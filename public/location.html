이용 안내

  • 내 휴대전화의 GPS 위치를 실시간으로 보여줍니다.
  • 좌표는 이 화면에만 표시되며 서버로 전송하거나 저장하지 않습니다.
  • [동의]를 누르면 위치 권한 창이 나타납니다.
  • 권한 창에서 반드시 [이번에만 허용]을 눌러 주세요. (iPhone은 [한 번 허용]) 그래야 다음 접속 때 다시 묻습니다.
다른 허용(항상 허용 등)을 눌렀다면?
Chrome: 주소창 왼쪽 아이콘 → 권한 → 위치 → '매번 확인' 또는 재설정
iPhone: 설정 → Safari → 위치 → '묻기'
